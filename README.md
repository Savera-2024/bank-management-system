# Bank_Management_System

## 📌 Project Description

The **Bank Management System** is a console-based Java application that simulates core banking functionalities. The system is designed using **Object-Oriented Programming (OOP)** principles to ensure modularity, scalability, and maintainability. It allows users to perform essential banking operations such as account management, transactions, and balance inquiries in a structured manner.

This project was developed as an academic submission to demonstrate practical implementation of Java programming concepts and real-world system modeling.

## ⚙️ System Features

* Account creation with unique account identifiers
* Secure deposit and withdrawal processing
* Real-time balance inquiry
* Customer data management
* Transaction validation and exception handling
* Modular class-based architecture

## 🧠 Technical Architecture

* **Programming Paradigm:** Object-Oriented Programming (OOP)
* **Core Components:**

  * Account Class – Handles account details and balance logic
  * Customer Class – Stores and manages customer information
  * Transaction Logic – Manages deposits, withdrawals, and validations
  * Main Class (`Main.java`) – Application entry point and control flow

## 🛠️ Technologies & Tools

* **Language:** Java (JDK 8+)
* **IDE Support:** NetBeans / IntelliJ IDEA / Eclipse
* **Java Concepts Used:**

  * Classes and Objects
  * Encapsulation and Abstraction
  * Conditional Statements & Loops
  * Exception Handling
  * Input Handling (Scanner)
